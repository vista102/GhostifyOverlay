# Ghostify Overlay 0.5.1 레벨 해시 검증

2026-10-31. 어템의 레벨 식별자를 파일 경로에서 플레이 데이터의 해시로 변경했습니다.

## 판별 기준과 원본 참고

[JipperResourcePack PlayCount.cs](https://github.com/Jongye0l/JipperResourcePack/blob/ac6d6410571ee7d585aedce7f5085de34f615af2/JipperResourcePack/OverlayContents/PlayCount.cs)의 `GetMapHash` / `GetHash`를 참고했습니다. 로컬 원본의 SHA256은 `c1f43f9ec5c83aef2e550871b1c39310e4277cb059c09354259765b7fd7f8e5e`입니다. 기존 BSD 전문을 유지하고 참고 범위와 원본 파일 기록을 갱신했습니다.

- 공식 레벨은 `ADOBase.currentLevel`의 공식 ID를 해시합니다.
- 커스텀 레벨은 원본과 같은 판별 대상을 사용합니다. 구형 레벨은 `leveldata`, 신형은 `floorAngles`와 주요 이벤트의 종류·위치·값·순서를 사용합니다.
- 포함 이벤트: SetSpeed, Twirl, Hold, MultiPlanet, Pause, AutoPlayTiles, ScaleMargin, Multitap, KillPlayer. 원본처럼 이 목록 밖의 연출·표시 이벤트와 곡명·작곡가·경로·파일명은 제외합니다.
- 원본 MD5 / JALib 직렬화와 별개의 `Ghostify.Gameplay.v1` 바이너리 규격과 SHA256을 사용합니다. 키 형식은 `level:v1:<64자리 소문자 HEX>`입니다. 공식·커스텀 및 구형·신형 데이터의 경계를 구분합니다. 원본 `Plays.dat`를 가져오는 기능은 포함하지 않습니다.
- 같은 데이터의 복사·이동·이름 변경은 Full 누적을 공유하고, 같은 경로라도 타일이나 위 주요 이벤트가 달라지면 별도 기록입니다. 일반 Attempt / Prac Attempt의 맵 퇴장 초기화 규칙은 유지합니다.

## 저장 이전과 안전 처리

현재 열린 커스텀 맵 경로에 해당하는 이전 `path:` 기록을 해당 해시의 Full / Full Prac 누적에 한 번 합산하고 이전 키를 제거합니다. 공식 레벨은 확인된 `world:` 기록을 이전합니다. JSON 원자 저장과 기존 `.bak` 백업을 사용하며 일반 설정 스키마는 변경하지 않습니다.

경로 기록에는 과거의 파일 내용이 없으므로, 이전은 현재 열린 맵과 일치하는 기존 경로를 근거로 수행합니다. 업데이트 전에 파일을 옮겨 원래 경로와 연결할 수 없는 기록, 열지 않은 맵, 모호한 `name:` / `song:` 기록은 삭제하거나 임의로 합치지 않습니다. 과거에 같은 경로의 내용을 이미 바꿨는지까지 복원할 수는 없습니다. 같은 해시의 다른 경로 기록도 그 경로의 맵을 열면 이어서 합산합니다.

해시는 판 시작 때 새로 계산하고 일반 프레임에서는 캐시를 재사용합니다. 에디터에서 저장하지 않은 타일·이벤트 변경도 다음 시도에 반영됩니다. 로딩 중에는 집계를 보류하고 준비가 끝난 뒤 대기 중 시도를 한 번 집계합니다. 오류·불완전한 값은 이름·경로·`unknown-level` 키로 대체하지 않으며, 오류 시 재계산에 대기 간격을 둡니다. 집계·이전은 음수 및 정수 오버플로를 방지합니다.
