# Ghostify Overlay 0.4.2 검증

2026-10-04. 사진을 포함한 피드백 10개와 추가 요청인 발 6키 제거를 반영하고 설치 EXE를 제작했습니다. 사용자 요청에 따라 EXE만 만들었으며 실제 게임에는 설치하지 않았습니다.

## 반영 및 원인

- 곡명: JipperResourcePack의 Combo.OnHUDTextAwake처럼 원래 게임 곡명 표시의 줄바꿈을 공백으로 정리합니다. 중앙 상단의 진행 막대와 콤보 사이에 uGUI/TMP로 표시하고, 네이티브 표시 초기화 전에는 작곡가·곡명 메타데이터를 사용합니다. 곡명 섹션의 위치는 좌상단과 독립적입니다.
- 사진의 `<color=#00000000>` 노출: 레벨 메타데이터에 서식 태그가 있었는데 기존 오버레이가 richText=false로 그대로 출력했습니다. 알려진 서식 태그를 제거해 내용만 표시합니다. richText를 켜는 방식은 해당 태그의 완전 투명 색 때문에 곡명이 사라지므로 사용하지 않습니다. 빈 메타데이터와 ScnGame/ScnEditor 자리표시도 처리했습니다.
- 긴 곡명: Ellipsis를 제거하고 화면 너비와 현재 배율에 맞춰 줄바꿈 및 필요한 높이를 계산합니다. 문자열을 줄이거나 자르지 않습니다. 크기 측정 결과는 텍스트·너비가 바뀔 때만 갱신합니다.
- 판정범위 동반 이동: Timing Scale 위치를 세부판정의 RectTransform 및 배율에 더하던 것이 원인이었습니다. 공통 네이티브 판정 미터 기준점에서 각자의 저장 좌표로 계산합니다. 이전 화면상 Timing Scale 위치는 schema 4 → 5 전환에서 보존하며 이후 세부판정 이동·배율과 독립적입니다.
- 10키: 상단 8개 50×50, 하단 KPS 폭 158 / 키 두 개 50×50 / Total 폭 158. 하단 키 X=162,216, Total X=270.
- 12키: 상단 8개 50×50, 하단 KPS 폭 104 / 키 네 개 50×50 / Total 폭 104. 하단 키 X=108,162,216,270, Total X=324. 키 사이 간격 4와 전체 폭 428을 유지하며 아래 키는 같은 열의 레인 풀에 연결합니다. 실제 설정 미리보기와 키뷰어가 같은 geometry를 사용합니다.
- 배치 제거: 손 20키와 발 6키 enum·배열·선택지·런타임 루틴을 제거했습니다. 기존 enum의 숫자를 재사용하지 않아 손 10키, 발 8키·16키 저장값을 보존합니다. JSON의 숫자/문자열 기존 스타일은 역직렬화 전에 손 16키 / 발 4키로 전환하며 유지 가능한 첫 16개 / 4개 키·이름·고스트 등록을 옮깁니다. 누적 기록을 위해 발 키 인덱스 20부터 시작하는 기존 저장 구조는 유지합니다.
- 발키 홀드: Start_Rewind 상태 초기화에서 모든 손·발 키를 시작 입력으로 억제하던 경로를 수정했습니다. 손·고스트 시작 키 억제는 유지하고, 발키는 물리 눌림 상태를 복구합니다. 반복 재시작에서도 유지하고 실제 해제 시 꺼지며 복구 자체는 누적·KPS를 증가시키지 않습니다.
- 색상: 일반 키와 KPS, Total에 독립적인 팔레트를 적용합니다. KPS와 Total은 각각 배경·테두리·이름·숫자 색을 HEX 및 팔레트로 편집·저장·초기화할 수 있습니다. 기존 키 색상은 두 카운터에 각각 복사해 이전 모습을 유지하고 이후에는 독립적으로 변경합니다. 설정 미리보기에도 카운터별 색을 적용합니다.

총 **786개** 실행 검사가 통과했습니다. 새 검사에서 실제 OverlayController.Update가 독립 좌표 계산을 사용하고 실제 Key.UpdateKey가 카운터별 팔레트 선택을 사용하는 것도 DLL의 호출 대상으로 확인했습니다.

추가로 patch 26개 대상의 메타데이터를 확인하고 24개 생성을 성공했습니다. Unity 밖에서는 실행할 수 없는 ECall 대상 2개를 구분했으며 수동 입력 후크 3개도 생성·정리를 확인했습니다. 테스트에서 실제 게임 메서드는 실행하지 않았습니다.

Release 빌드 및 Git diff whitespace 검사, 원본 DonQuixote 2,336개 파일 해시 보존을 확인했습니다. EXE 내 14개 파일의 SHA256이 ZIP 및 Release와 일치하며 사용자 설정은 배포에 포함되지 않습니다. 배포 EXE의 읽기 전용 검증으로 설치된 3.4.0 alpha build 25590222 SDK를 확인했습니다. 실행 중 설치 차단 및 한글 경로 fixture의 무변경도 확인했습니다.

실제 설치된 0.4.1의 GhostifyOverlay.dll, Info.json, GameCompatibility.json 및 UMM Params.xml의 검사 전후 해시는 같습니다. 게임이 실행 중이므로 배포 EXE의 실제 게임 설치와 인게임 화면·물리 발키·사망 동작의 육안 확인은 하지 않았습니다. 위 홀드·곡명·위치·색상 검사는 실제 모드 DLL 로직과 production 배치 코드의 API 대체 검사에 해당합니다.
