# 0.4.13 기본 설정 반영 검증

2026-10-27. 사용자가 제공한 ZIP의 `settings.json`, `keyviewer.json`, `layout.json` 설정을 새 설치·초기화의 기본값으로 반영했습니다. UMM 0.32.5와 ADOFAI 3.4.0 alpha build 26044349 지원을 유지합니다.

## 기본값

- 오버레이 수치·시도 횟수는 흰색, 진행 막대는 `#FFC939FF`입니다. Accuracy와 이론 KPS는 기본적으로 숨기고 나머지 표시 항목·그룹 상태는 제공된 값과 같습니다.
- 오버레이 각 항목의 위치·크기를 제공된 배치로 변경했습니다.
- 손 키뷰어는 10키, 발 키뷰어는 끔, 게임 플레이 중에만 표시합니다. 키 지정·별칭·고스트 키는 모든 지원 배치에 대해 제공된 값으로 설정했습니다.
- 키 배경은 검정, 눌렀을 때 흰색, 테두리는 `#FFC939FF`입니다. 글자는 평소 흰색, 눌렀을 때 검정입니다. KPS·Total도 검정 배경·노란 테두리·흰 글자입니다.
- 상단·하단 레인은 각각 노랑·흰색, 고스트 레인은 `#0EB4FCFF`이며 고스트 레인 표시는 켜져 있습니다. 키 간격은 3, 가로 위치는 2, 높이·크기·레인 속도·레인 높이도 제공된 값과 같습니다. 키와 레인의 실제 크기는 변경하지 않았습니다.

`Tests/Data/FactoryDefaults.json`은 승인된 설정 대조 자료입니다. 누적 어템 사전은 비웠고, 키 입력 횟수·게임 입력 복원 기록·DLL·캐시·이전 설정 백업은 포함하지 않았습니다. 배포 패키지에 사용자 데이터 파일을 넣는 방식 대신 기존 설정 클래스의 기본값을 변경했습니다. 스키마와 기존 설정을 읽는 방법은 유지합니다.
