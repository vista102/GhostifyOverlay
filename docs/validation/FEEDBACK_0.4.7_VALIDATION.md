# Ghostify Overlay 0.4.7 검증

2026-10-06. 로컬 수정본과 설치 EXE를 준비했습니다. 실제 게임 설치와 GitHub 업로드는 하지 않았습니다.

## 변경

- 설정창의 오버레이·키뷰어 위치 숫자 입력 및 오버레이 크기 슬라이더를 없애고 화면 편집 버튼을 복구했습니다. 키 간격·레인 치수 설정은 유지합니다.
- 숫자 1~9로 기존 항목을 선택하고, 0으로 진행 막대를 선택합니다. Tab은 전체 10개 항목을 순환합니다. 키뷰어 페이지의 편집 버튼은 키뷰어를 바로 선택합니다.
- 방향키는 즉시 5px 이동하고 280ms 후 40ms 간격으로 반복합니다. Shift는 20px, Ctrl+↑↓는 배율을 0.05씩 바꿉니다. 렌더링 FPS와 독립적인 시간 기준을 사용하고 긴 프레임 정지의 이동량은 제한합니다.
- Enter로 배치를 저장하고 Esc·장면 변경·모드 해제·설정창 재진입은 편집 전 배치로 복구합니다. 모든 LayoutData 필드와 키뷰어 위치·배율을 스냅샷에 포함합니다. 편집 중 자동 저장은 대기하며 외부 저장 요청은 편집을 취소한 뒤 저장합니다.
- 편집 중 게임 입력 보호와 키뷰어 미리보기를 복구했습니다. 판정 범위·세부 판정과 진행 막대·곡 정보는 각각 독립적으로 움직입니다.
- 5개 그룹 카드 높이는 모두 340px, 멤버 격자는 모두 3행 영역으로 통일했습니다. 각 멤버 카드는 44px이며 행 사이 간격은 8px입니다.
- 원통형 토글 트랙은 56×32에서 46×26px로, 원형 손잡이는 26에서 20px로 줄였습니다. 44px 카드에서 트랙 위아래 여백은 9px, 손잡이와 트랙의 내부 여백은 3px입니다.
