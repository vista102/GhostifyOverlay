# Ghostify Overlay 0.4.6 검증

2026-10-06. 5개 그룹의 uGUI 설정 화면을 추가하고 이펙트 제거 및 키보드 섹션 편집 기능을 제거했습니다. 소스와 EXE는 로컬에 준비했으며 공개 업로드·실제 게임 설치는 수행하지 않았습니다.

## 변경과 저장 호환

- 이펙트 설정 탭, EffectsSettings, 관련 패치 7개, 복원 및 수명 처리, 기존 검사 코드를 제거했습니다. Harmony 카탈로그에는 입력 보호·통계·판정 색·결과 순서·고스트 입력의 5개 그룹만 남습니다.
- 16키 런타임과 키 등록 미리보기에서 KPS / Total을 항상 구성합니다. 이전 `ShowTotalKpsKey16:false` 값은 무시하며 키·레인·간격 설정과 기록은 보존합니다.
- 레인 색상의 UI 이름만 상단 레인 / 하단 레인으로 변경했습니다. 기존 색상 저장 키는 유지합니다.
- 오버레이를 진행/정확도, 플레이 수치, 진행/곡 정보, 판정, 시도 횟수의 5개 그룹으로 나눴습니다. 왼쪽 그룹 선택과 오른쪽 상세 카드, 2열 항목 토글을 사용합니다. 그룹 전체 OFF는 내부 선택을 덮어쓰지 않습니다.
- Pitch와 누적 세부 판정을 독립적으로 켜고 끌 수 있습니다. 세부 판정은 기존처럼 인게임 세부 표시 설정도 따릅니다. 이전 스키마에서는 세부 표시를 기존 누적 판정 표시값에서 이전해 배치와 표시 상태를 유지합니다.
- X / Y 입력과 크기 슬라이더·숫자 입력을 각 그룹 안에 구성했습니다. 그룹 1·2·5는 각 묶음, 그룹 3·4는 각 렌더링 항목을 조절합니다. 새 진행 막대 배치 기본값은 기존 위치·크기입니다. 저장한 다른 배치는 초기화하지 않습니다.
- LayoutEditorController와 별도 섹션 편집 버튼·방향키 모드를 제거했습니다. UI 배치 변경은 기존 원자적 layout.json 저장 방식으로 자동 저장합니다. UI / 오버레이 폰트 안내 문구도 제거했습니다.
