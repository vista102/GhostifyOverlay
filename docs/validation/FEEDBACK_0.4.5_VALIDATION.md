# Ghostify Overlay 0.4.5 검증

2026-10-06. 아래 6가지 피드백을 반영해 EXE와 ZIP을 제작했습니다. 실제 게임에는 설치하지 않았습니다.

## 변경

- FPS: 100ms마다 프레임 수 / 실제 경과 시간으로 새 값을 계산합니다. 250FPS에서 1초 동안 정확히 10회 갱신되는 것을 확인했습니다. 잘못된 시각 값은 무시합니다.
- 시도 횟수: `Prg Attempt`와 `Full Prg Attempt`를 `Prac Attempt` / `Full Prac Attempt`로 바꿨습니다. 기존 세션·전체 기록의 집계와 저장 키는 유지합니다.
- 글자 색: TextColor 설정 필드와 설정 행을 제거했습니다. 좌우 글자·콤보 이름·곡 정보·타이밍 스케일은 렌더러에서 불투명 흰색으로 고정합니다. 수치·시도 횟수·진행 막대 및 키뷰어 색상은 계속 조절할 수 있습니다. 이전 TextColor 값은 무시하며 새 저장 파일에 기록하지 않습니다.
- 모드 폴더: EXE는 `Mods/Ghostify Overlay`에 설치합니다. 이전 `DonQuixoteOverlay`는 Info ID·경로 검증과 전체 백업 후 이름을 변경하고, 실패 시 원래 이름과 파일·UMM 설정을 복원합니다. 두 폴더가 모두 있으면 무손상으로 중단합니다. 내부 UMM ID는 기존 활성화·단축키 설정 호환을 위해 유지합니다. [공식 UMM 로더](https://github.com/newman55/unity-mod-manager/blob/master/UnityModManager/ModManager.cs)는 폴더를 순회해 Info ID와 실제 경로를 별도로 사용합니다.
- Pitch: 1배는 100%, 1.5배는 150%로 표시합니다. 최대 소수점 두 자리까지 보존합니다. 실제 재생 배율은 변경하지 않습니다.
- 키 간격: 설정에 0~30 입력을 추가했습니다. 기본 4에서 기존 좌표가 유지됩니다. 손·발·카운터·미리보기가 같은 배치 함수를 사용합니다. 손 50×50, 발 30×30 및 레인 너비 50/40, 레인 높이·속도는 유지합니다. 카운터 폭은 새 행 폭에 맞춥니다. 기존에 맞닿아 있던 발키 두 행은 기본 배치를 유지하며 간격 증가분만 추가하고 음수 간격은 방지합니다. 큰 배치의 설정 미리보기는 화면에 맞게 축소합니다.
