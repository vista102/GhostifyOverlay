# Ghostify Overlay 0.4.0 검증

요청한 수정과 추가 오버레이 색상 설정을 구현하고 설치 EXE·모드 ZIP을 만들었습니다. 사용자의 EXE만 제작 요청에 따라 실제 게임에는 설치하지 않았습니다. 실제 설치는 0.3.2이며, 테스트 설치는 프로젝트 안의 가짜 게임 폴더에서만 진행했습니다.

## 반영 사항

- 게임 맵 진입 시 키뷰어 표시, 에디터에서는 재생 여부에 따라 표시.
- 실제 손·발 배치를 클릭해 우측 메뉴에서 키·표시 이름·손 키별 고스트 키 편집. 런타임과 미리보기의 배치 정보 공유. 원본 키 크기·레인 연결 보존.
- 채워진 고스트 레인, 기본 하늘색 #00C8FF, 기존 사용자 지정 색 보존.
- 키·레인·오버레이 색의 HEX 입력과 HSV/불투명도/색상 팔레트. 적용·취소·색상만 초기화 지원.
- 다음 타일의 Timing Scale을 세부 누적 위에 배치. 다른 저장 배치는 보존.
- 오버레이·키뷰어에 Gmarket Sans Light, 중앙 X 흰색, Pitch 아래 1초 단위 FPS.
- 진행도와 막대 및 체크포인트 범위를 같은 타일 수 기준으로 계산.
- 맵 재시작 중 Session Attempt 유지, 맵 종료·다른 맵 진입 시 Session 초기화, Full 기록 보존.
- 설치 창 상단 제목 위치 조정, 원본 모드 비활성화 안내 문구 제거.
- 통계가 변하지 않은 상태에서도 색상 적용 시 캐시 갱신.
- 설치 중 게임이 시작되면 UMM 수정 전에 중단하고 이전 파일 복원.
