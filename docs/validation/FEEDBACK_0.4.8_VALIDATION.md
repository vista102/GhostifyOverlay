# Ghostify Overlay 0.4.8 어템 검증

2026-10-12. 제보는 0.4.7에서 어템 숫자가 증가하지 않는 증상입니다. 첨부 로그에는 모드 정상 로딩과 에디터 재생·재시작이 기록돼 있으나 당시 어템 제외 설정 값은 없어 제보 환경의 직접 원인을 확정할 수 없습니다.

## 수정과 근거

- 실제 설치된 3.4.0 alpha의 `scrController.SetupImportantVariables` IL에서 `freeroamInvulnerability`가 Persistence의 자유 이동 구간 무적 옵션을 그대로 읽는 것을 확인했습니다. 이를 맵 전체 무적과 동일하게 취급해 모든 어템을 제외하던 조건을 제거했습니다. 자동플레이·noFail·무한 판정 범위 제외는 유지합니다.
- 실제 `scnGame.Play`와 게임 시작 코드에서는 `Start_Rewind` 호출 후 `startedFromCheckpoint`를 갱신합니다. 패치는 시작 정보를 예약하고 다음 프레임에 확정된 상태로 집계합니다. 구간 재생 후 처음부터 재시작할 때 이전 체크포인트 상태가 남아 일반 어템 대신 Prac에 집계되는 상황도 방지합니다.
- 예약된 시작은 프레임 갱신으로 중복 집계하지 않으며 잠깐의 null controller를 견딥니다. 맵 종료는 예약을 취소합니다. 일반 어템·구간 어템의 세션과 Full 누적 저장 방식은 유지합니다.
- 집계 결과와 자동플레이·무적 제외 이유를 게임 로그에 한 번씩 남겨 후속 제보에서 구별할 수 있도록 했습니다. 기존 기록과 배치는 초기화하지 않습니다.
