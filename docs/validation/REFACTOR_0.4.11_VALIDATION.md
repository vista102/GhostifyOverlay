# 0.4.11 구조 리팩터링 검증

2026-10-22. 0.4.10의 사용자 기능·독립형 uGUI·설정 및 누적 기록 형식을 유지하면서 소스 구조와 서비스 의존성을 정리했습니다. 개발 방법은 [빌드·검사 안내](../development/BUILD_AND_TEST.md), 책임·의존성은 [코드 구조](../architecture/ARCHITECTURE.md)에 있습니다.

## 변경 범위

- 흩어져 있던 프로덕션 C# 43개 파일의 타입을 책임에 맞게 분리했습니다. 최종 소스는 `src/Mod` 121개, `src/Installer` 16개 파일입니다. 설치기 테스트는 `Tests/Installer`로 옮겼습니다.
- 저장·복구·원자 쓰기·상태 표시, 저장 예약, 생명주기, 게임 수치·메타데이터, 권한 상승 실행을 별도 계약과 구현으로 분리했습니다.
- 초기화 실패·종료 실패와 로그 출력 실패에도 자원 정리 및 저장 재시도를 수행합니다. 기존 저장 참가자 순서와 입력 횟수의 지연 저장을 유지합니다.
- 검증·계획·조사 문서를 `docs/`로 옮겼고 루트에는 사용법·라이선스·AI 생성 기록만 남겼습니다. 원래 비공개로 제외된 로컬 기록은 `docs/local`에서도 Git에서 제외합니다.
- 빌드·분석·테스트 스크립트의 경로와 문서 링크를 갱신했습니다. Windows PowerShell 5.1의 한글 리터럴을 위해 스크립트는 UTF-8 BOM을 사용합니다.
