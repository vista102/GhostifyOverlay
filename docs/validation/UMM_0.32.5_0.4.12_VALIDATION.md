# 0.4.12 UMM 0.32.5 호환성 검증

2026-10-27. 0.4.11의 기능·독립형 uGUI·사용자 데이터 형식을 유지하면서 UMM 최소 버전을 0.32.5로 변경했습니다. 지원 게임 SDK는 3.4.0 alpha build 26044349입니다.

## 변경

- 실제 설치된 `UnityModManager.dll` 0.32.5.0과 `0Harmony.dll` 2.3.6.0을 참조해 다시 빌드했습니다.
- `Info.json`, `GameCompatibility.json`과 설치기의 최소 버전 판정을 통일했습니다. 설치기는 패키지의 최소 버전 정보를 사용하며, 잘못됐거나 누락된 정보는 거부합니다.
- `Build.ps1`은 참조하는 UMM이 기준 버전과 다르면 컴파일 전에 중단합니다. 별도 SDK는 `-ModManagerDir`로 지정할 수 있습니다. 설치기 패키징도 모드 버전·최소 UMM 정보의 일치 여부를 확인합니다.
- 기존 설정·키 배치·누적 기록 형식과 UMM 진입점은 유지합니다.
