# 0.5.1 스크롤·창 테두리·설치기 이미지 검증

2026-10-13. 기존 0.5.0의 UMM 내 uGUI 설정 화면을 유지합니다.

## 변경

- 내부 ScrollRect의 휠 감도를 기본값 1에서 80으로 올렸습니다. 클릭·드래그 좌표 변환은 그대로 사용합니다.
- 설정창과 색상 팔레트 창의 바깥 모서리를 직각으로 바꿨습니다. 반경 0의 채움은 모서리까지 불투명하며, 테두리는 한 픽셀 두께의 사각형입니다. 내부 카드·버튼·토글의 모양은 유지합니다.
- 설치기의 이미지와 ICO를 새로 제공한 PNG로 교체했습니다. PNG는 원본 그대로이고, ICO는 기존 빌드 과정에서 크기별로 변환합니다. 설치기 미리보기도 갱신했습니다.

## 검사

| 검사 | 결과 |
|---|---|
| 실제 3.4.0 alpha SDK Release 빌드 | 성공 |
| production UMM host·입력, inert Unity API | 38개 통과: 내부·외부 휠 전달, clip, 클릭·드래그, 자원·입력 복구 |
| 최종 DLL UMM SDK·좌표 변환 | 15개 통과 |
| 최종 DLL 창 표면 픽셀 생성 | 19개 통과: 사각 모서리 채움·테두리, 내부 둥근 컨트롤 유지 |
| 실제 Windows Forms 설치기 UI | 38개 통과: 버튼 상태, 종료, 글꼴·GDI 자원 해제 |
| 배포 EXE 내장 ZIP·독립 ZIP·Release | 14개 파일 SHA256 일치, 라이선스 원문 검사 통과 |
| 배포 EXE 게임 SDK 검사 | 읽기 전용으로 설치된 3.4.0 alpha 확인 |
| 배포 EXE 이미지·아이콘 | 현재 소스 자산과 SHA256 일치, PNG는 사용자 제공 원본과 바이트 단위 일치 |
| 배포 EXE 설치 화면 | 미리보기를 생성해 새 이미지가 잘리지 않고 표시되는 것 확인 |

미리보기의 최초 실행은 샌드박스의 Steam 레지스트리 접근 제한으로 실패했습니다. 승인된 읽기 전용 실행으로 다시 생성해 성공했습니다. 실제 게임 설치와 GitHub 업로드는 수행하지 않았습니다. 실제 Unity 안에서 휠 이동량의 체감과 창 모서리를 확인하는 검증은 아직 하지 않았습니다.
