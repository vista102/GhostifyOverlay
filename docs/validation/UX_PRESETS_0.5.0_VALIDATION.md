# Ghostify Overlay 0.5.0 검증

2026-10-27. 독립형 uGUI 설정창의 두 탭, 화이트 / #FFC939 테마와 기존 기본값을 유지하고 분류 탐색과 키 배치 프리셋을 추가했습니다. 이전 UMM 내부 삽입 실험 버전과 구분되는 0.4.14 기반의 새 0.5.0입니다.

## 동작과 저장

- 오버레이는 기존 다섯 그룹과 공통 스타일, 키뷰어는 키 배치·프리셋 / 표시·간격 / 레인 / 색상 / 입력으로 구성합니다. 전체 표시와 화면 편집 버튼은 고정하고 상세 설정만 스크롤합니다. 분류별 스크롤 위치를 기억합니다.
- 키 배치 화면은 기존 960×720 창에서 프리셋, 배치 선택, 실제 배치 미리보기, 키별 편집과 안내가 첫 상세 영역에 들어갑니다. 키 색상은 기본/누름 상태를 나란히 표시하고 KPS·Total은 선택해서 편집합니다.
- 프리셋은 이름, 선택한 손·발 배치, 입력 키, 표시 이름, 고스트 키만 저장합니다. 색상·간격·위치·레인·표시·입력 옵션과 누적 기록은 공통 설정으로 유지합니다. 선택하지 않은 배치의 등록값도 유지합니다.
- 첫 실행에서 현재 구성을 ‘기존 설정’으로 저장하고 기본 10·12·16키를 제공합니다. 목록 미리보기만으로 현재 구성은 바뀌지 않습니다. 명시적 불러오기·덮어쓰기·새 저장·이름 변경·복제·삭제·공유와 이전 구성으로 되돌리기를 지원합니다.
- `UserData/keyviewer-presets.json`은 별도 스키마 1의 원자 저장·백업·손상 복구를 사용합니다. 활성 프리셋과 적용 전 구성이 재실행 후에도 유지됩니다. 기존 설정 JSON 스키마와 UMM ID / 진입점은 유지합니다.
- 공유 파일은 `Ghostify.KeyBindings` 형식과 버전 1을 명시해야 하며 256KB까지 받습니다. 키 개수, 지원 배치, 유효 키 코드, 배열 길이, 프리셋 이름 48자·키 표시 이름 32자와 제어 문자를 검증합니다. 사용자 이름은 파일 경로로 쓰지 않고 UI에서 일반 텍스트로 표시합니다.
- 불러오기 때 키 등록을 취소하고 키뷰어를 한 번 재구성해 입력 키 자동 연동을 요청합니다. 고스트 키 제외 규칙은 유지합니다. 키 간격 드래그는 100ms 정착 후 한 번 재구성하며 입력 키를 재연동하지 않습니다. 레인 속도·높이 변경은 실행 중 참조값만 갱신합니다.
- 화면 편집은 기존 키보드 조작과 독립 배치를 유지합니다. 표시 중인 선택 대상에 테두리를 표시하며, 사용자 저장·취소 때만 원래 설정 화면으로 돌아옵니다. 장면 변경·모드 종료·외부 취소에서는 창을 다시 열지 않습니다.
- 게임 세부 판정 설정과 외부 KeyboardChatterBlocker로 인한 대기 상태를 해당 설정에서 설명합니다. 저장 대기·완료와 오류 요약을 하단에 표시하고 자세한 진단은 별도 창으로 확인합니다.

## 검증 범위

프리셋 실제 서비스·저장·어댑터 검사 67개, 전체 production 설정창 빌더·콜백 검사 56개를 통과했습니다. 15가지 손·발 조합, 키·프리셋 이름 재저장, 깊은 복사, 이전 구성 복원, 오류 파일·저장 실패, 기존 설정 보존, 분류·스크롤 기억, 입력 연동 횟수, 화면 편집 복귀·연속 이동·배치 독립성을 검사합니다.

설정 화면 참고 이미지는 production UI 트리를 inert API에서 실행한 좌표를 그린 것으로, Unity 인게임 렌더링 캡처가 아닙니다. 실제 게임 설치·인게임 시각 및 플레이 검증은 수행하지 않았습니다. 외부 모드 조합과 Unity ECall의 런타임 한계는 기존 검증 범위와 같습니다.
