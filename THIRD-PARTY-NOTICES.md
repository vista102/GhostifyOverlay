The key viewer in `KeyViewerContents` is derived from [JipperResourcePack](https://github.com/Jongye0l/JipperResourcePack) by Jongyeol, commit `ac6d6410571ee7d585aedce7f5085de34f615af2`, under the BSD-3-Clause license. The full copyright notice, license conditions and disclaimer are included in `Licenses/JipperResourcePack-BSD-3-Clause.txt`. Original file hashes are recorded in `Licenses/JipperResourcePack-source.json`.

The port preserves the hand/foot styles, slot counters, the 10-key counter mapping, KPS window and Key/RawRain/Rain/RainPool/RainManager relationships. Integration changes replace JALib/IMGUI settings with this mod's runtime uGUI, use its own data directory and atomic JSON count snapshots, and dispatch captured events on the Unity main thread. The 16 hand cells retain the upstream 50x50 dimensions and 4-unit gaps; text fits inside the fixed frames. Pool limits, stale rain reference cleanup, focus/scene reset and input hook cleanup are included. The assets are generated by this mod; JipperResourcePack's font/image bundle is not bundled. Ghost rain is a plain filled uGUI Image, sharing the normal rain rendering mechanism; no upstream ghost texture is bundled.
