# Ghostify Overlay

얼불춤의 플레이 정보와 키 입력을 보여주는 오버레이 모드입니다.

- 누적·세부 판정, 콤보, 진행도, 정확도, 시도 횟수, 곡 정보, Timing Scale, FPS 표시
- 손·발 키뷰어, 고스트 레인, KPS·입력 횟수 표시
- 그룹별 표시, 화면에서 위치·크기 편집, 오버레이 색상 조절
- 이름을 붙여 저장하는 키 배치 프리셋과 JSON 공유

## 설치

**지원 환경:** Windows 10/11, 얼불춤 3.4.0 alpha(build 26311090), Unity Mod Manager 0.32.5 이상, .NET Framework 4.8.

1. 설치 파일 `GhostifyOverlay-Setup-0.5.1.exe`를 준비합니다.
2. 게임을 종료한 뒤 EXE를 실행하고, 게임 폴더를 확인해 **설치하기 / 업데이트**를 누릅니다.
3. 게임을 실행하고 Unity Mod Manager에서 **Ghostify Overlay**를 활성화합니다.

업데이트 시 기존 설정·키 배치·누적 기록은 유지됩니다. 새 설치의 기본값은 검정 배경·흰 글자·노란 테두리, 하늘색 고스트 레인과 10키 배치입니다.
모드는 `Mods/Ghostify Overlay`에 설치하며, 이전 `DonQuixoteOverlay` 폴더는 EXE 업데이트 시 자동 이전합니다.

## 사용 방법

**Alt+D**로 설정창을 열고, **Esc** 또는 우측 상단 **X**로 닫습니다. 왼쪽 분류를 선택한 뒤 오른쪽에서 설정합니다. 상세 영역은 휠로 이동하며 분류별 스크롤 위치를 기억합니다. 팔레트·프리셋 창·키 등록 중 Esc는 해당 작업만 취소합니다.

- **오버레이:** 왼쪽에서 5개 그룹 중 하나를 선택합니다. 그룹 전체와 각 항목을 따로 켜고 끌 수 있습니다.
- **곡명 / 작곡가:** Ghostify 곡 정보가 표시되면 게임 기본 곡 정보는 자동으로 숨기고, 끄면 원래 상태로 돌립니다. ADOFAI Tweaks의 숨김 설정은 유지합니다.
- **행간·색상:** 오버레이 → 공통 스타일에서 조절합니다. 행간 기본값 0은 기존 간격입니다.
- **위치·크기 편집:** 상단 버튼을 누르면 화면에서 조절합니다. 숫자 1~9·0 또는 Tab으로 항목을 고르고, 방향키로 이동합니다. 길게 누르면 연속 이동하며 Shift로 빠르게 이동합니다. Ctrl+↑↓로 크기를 바꾸고 Enter로 저장, Esc로 취소하면 설정창으로 돌아옵니다.
- **색상:** 수치·시도 횟수·진행 막대 색상을 조절합니다. 글자·곡 정보·타이밍은 흰색으로 고정하며, Pitch는 백분율, FPS는 초당 10회 갱신합니다.
- **키 배치·프리셋:** 손·발 배치를 선택한 뒤 미리보기의 키를 클릭합니다. 오른쪽에서 입력 키·표시 이름·고스트 키를 설정하고, **새로 저장**으로 이름을 붙여 보관합니다. 첫 실행 때 현재 구성은 **기존 설정**으로 저장합니다.
- **프리셋 불러오기:** 목록에서 미리 확인하고 **불러오기**로 적용합니다. **이전 구성으로**를 누르면 직전 구성으로 되돌립니다. 수정한 현재 구성은 자동 저장되며, 프리셋 갱신은 **⋯ → 현재 구성으로 덮어쓰기**를 사용합니다.
- **프리셋 관리·공유:** **⋯**에서 이름 변경·복제·삭제·JSON 가져오기·내보내기를 선택합니다. 가져오기는 파일 전체 경로를 입력하며, 내보낸 파일은 **프리셋 폴더 열기**에서 확인합니다. 프리셋에는 손·발 배치, 입력 키, 키 표시 이름, 고스트 키가 저장됩니다. 색상·레인·위치·입력 옵션은 공통 설정입니다.
- **키 간격:** 키뷰어 → 표시·간격에서 0~30으로 조절합니다. 기본값은 3이며 키·레인의 크기는 바뀌지 않습니다.
- **키·KPS·Total 색상:** 키뷰어 → 색상에서 대상을 선택합니다. 레인 색상은 레인 분류에서 조절합니다.
- **채터링 차단:** 키뷰어 → 입력에서 켜고 차단 간격을 0~500ms로 조절합니다. 기본값은 OFF / 100ms이며 플레이 중에만 적용합니다. 기존 KeyboardChatterBlocker가 활성화돼 있으면 내장 차단은 대기합니다.

색상은 HEX 코드로 입력하거나, 입력칸 옆의 색상 네모를 눌러 팔레트에서 선택합니다.

키뷰어의 **게임 입력 키 자동 연동**을 켜면 등록한 손·발 키가 게임의 **특정 키만 입력으로 간주** 목록에 반영됩니다. 고스트 키는 제외됩니다.

판정 텍스트 크기·숨기기는 게임 설정에서 변경합니다. 게임에서 세부 판정 표시를 끄면 세부 누적 오버레이도 함께 숨겨집니다.

16키의 KPS / Total은 항상 표시됩니다. 레인 색상은 **상단 레인**과 **하단 레인**에서 지정합니다.

시도 횟수는 판 시작 시 자동플레이·맵 전체 무적 여부로 집계합니다. 시작 후 모드를 바꿔도 이미 집계한 횟수는 유지합니다. 자유 이동 구간 무적 옵션은 일반 시도 집계를 막지 않습니다. Attempt / Prac Attempt는 맵을 나가면 초기화하고 Full 누적은 유지합니다.

레벨은 파일 경로 대신 타일 데이터와 주요 플레이 이벤트의 해시로 구분합니다. 같은 맵은 파일을 옮기거나 이름을 바꿔도 Full 기록을 공유하며, 같은 경로의 타일·주요 이벤트가 바뀌면 별도로 집계합니다. 기존 경로 기록은 해당 경로의 맵을 열 때 해시 기록으로 이전합니다. 확인할 수 없는 이전 경로의 기록도 삭제하지 않습니다.
