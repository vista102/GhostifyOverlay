## 설치

설치 파일은 **GhostifyOverlay-Setup-0.4.3.exe**입니다. 소스에서 빌드하면 `dist` 폴더에 생성됩니다. Windows 10/11, .NET Framework 4.8, Unity Mod Manager 0.33.0 이상이 설치된 얼불춤 **3.4.0 alpha build 25590222 (r150, Unity 6000.3.21f1)**을 대상으로 합니다. 설치 창에서 게임 DLL 지문 일치 여부와 개발 대상 버전을 확인할 수 있습니다. 다른 빌드는 미검증으로 표시합니다.

게임을 완전히 종료하고 EXE를 실행한 뒤 자동으로 찾은 게임 폴더를 확인하고 **설치하기 / 업데이트**를 누릅니다. 직접 폴더를 선택할 수도 있습니다. 기존 키 색상·배치·설정·누적 기록은 유지하고 이전 모드·UMM 설정을 자동으로 백업합니다. 설치 실패 시 변경한 파일을 복원합니다. 첨부 캐릭터를 설치 화면과 EXE 아이콘에 사용했습니다. 자세한 제작·복원 안내는 [설치 프로그램 문서](Installer/README.md)에 있습니다.

0.4.0은 게임 내장 초정확 판정과 트래커를 사용합니다. 자체 초정확 계산, 판정 크기·숨기기 설정, 자체 키 제한 코드를 제거했습니다. 키뷰어 등록 키는 게임 내장 허용 목록과 연동합니다. 세부 판정 표시를 게임에서 끄면 Ghostify의 세부 누적도 숨겨지고, 다시 켜면 숨겨진 동안을 포함한 최신 누적이 표시됩니다. 일반 누적과 정확도는 계속 표시합니다. 로비 이동은 시도 횟수에 포함하지 않고 실제 레벨 플레이만 기록합니다.

## 모드 사용

독립 UMM 모드입니다. **Alt+D**로 설정창을 열고 **Esc**로 닫습니다. 전체 설정창·통계 오버레이·키뷰어·레이아웃 안내를 흰색·노란색(#FFC939) uGUI/TMP로 구성했습니다. 노란 버튼·흰 표면에는 읽기 쉬운 어두운 글자를 사용합니다.

모든 설정 토글은 캡슐형 트랙과 흰색 원형 손잡이를 사용합니다. 켜짐은 노란색(#FFC939), 꺼짐은 회색이며 손잡이에 작은 그림자를 넣었습니다. 트랙과 손잡이는 늘어나지 않는 고정 비율로 표시하고 글자와의 간격을 확보합니다.

설정창 테두리는 카드 안쪽에 한 겹으로 그려 모서리와 직선의 두께를 맞췄습니다. 픽셀 정렬을 적용하고 이펙트 카드·슬라이더의 바깥쪽 좌우 경계를 통일했습니다. 우측 상단은 테두리·바탕 없는 X 닫기 버튼이며 아이콘 주변까지 클릭할 수 있습니다.

설정창·레이아웃 안내·설치 프로그램·통계 오버레이·키뷰어는 원래 Gmarket Sans Medium을 사용합니다. 없는 글리프는 Noto Sans KR로 보완합니다. 통계 오버레이에는 검은 그림자를 적용합니다. 게임 판정 텍스트의 원래 폰트·머티리얼은 유지하며 중앙 X는 흰색, +/-는 녹색(#60FF4E)입니다. 누적·세부판정은 기본 판정 색을 사용하며 색상 변경 기능은 제거했습니다. 세부 누적·결과창은 **빠름 / X / 느림** 순서입니다. 설치된 게임에서 빠른 판정은 PerfectMinus, 느린 판정은 PerfectPlus이며 Auto는 일반 Perfect·세부 X에 포함합니다. 일반 누적은 과부하가 왼쪽, 놓침이 오른쪽입니다. 유효하지 않은 초기 Accuracy/XAccuracy는 100.00%로 표시하고 실제 보너스로 100%를 넘는 정확도는 유지합니다.

## 0.4.3 피드백 반영

- 세부판정 누적을 실제 게임의 빠름 → X+Auto → 느림으로 연결했습니다. 부호 이름을 보고 순서를 정하던 오류를 수정했고 결과창도 같은 시간 순서를 따릅니다. 서로 다른 판정 수치를 실제 GetHitMarginInSec 반환값으로 만들어 연결을 검증합니다.
- 일반 누적은 Overload / Too Early / Very Early / Early / Perfect / Late / Very Late / Too Late / Miss 순서로 표시합니다. 과부하 수치는 여전히 FailOverload만 사용합니다.
- 삭제한 20키 전용 레인 3의 색상 설정·너비·그리기 경로를 제거했습니다. 일반 레인은 1·2, 고스트 레인은 기존 설정을 유지합니다. 고스트는 두 일반 레인 모두보다 뒤에 그립니다.
- 곡 정보는 중앙 상단 배치를 유지하고, 커스텀 맵은 작곡가·곡명 메타데이터로 항상 `작곡가 - 곡명`을 만듭니다. 기본 곡은 원래 레벨 캡션과 작곡가 크레딧을 같은 형식으로 조합합니다. 정보가 하나만 있으면 불필요한 구분자 없이 표시합니다.
- 누적·세부판정 색상 편집과 저장 필드를 제거했습니다. 이전 사용자 색상은 더 이상 적용하지 않으며 기본 판정 색을 사용합니다.
- 글자 색은 좌우 오버레이 이름·콤보 이름·작곡가/곡명·타이밍 스케일에 적용합니다. 수치 색은 좌우 수치·시간·FPS·콤보 숫자에 공통으로 적용합니다. 시도 횟수와 진행 막대 색은 별도로 설정합니다.
- 모든 색상 행에서 HEX 바로 옆의 정사각 색상 네모를 눌러 팔레트를 엽니다. HEX와 네모는 편집·팔레트 적용 후 함께 갱신되며 취소는 저장값을 바꾸지 않습니다.

0.4.3은 EXE만 제작하며 실제 게임에는 설치하지 않습니다. 검증 범위는 [FEEDBACK_0.4.3_VALIDATION.md](FEEDBACK_0.4.3_VALIDATION.md)에 기록합니다.

## 이전 0.4.2 피드백 반영

- 곡 정보는 게임의 원래 곡명 표시를 한 줄로 정리해 중앙 상단, 진행 막대와 콤보 사이에 표시합니다. 초기화 전에는 작곡가·곡명 메타데이터를 사용합니다. 색상·크기 등 서식 태그를 제거하고 투명한 색상 태그가 곡명을 숨기지 않도록 처리합니다. 빈 곡 정보와 장면 이름은 표시하지 않습니다.
- 긴 곡명은 화면 너비를 사용하고 필요한 경우 줄바꿈하며 말줄임 없이 표시합니다. 곡명 섹션은 좌상단 오버레이에서 분리해 위치를 조절합니다.
- Timing Scale과 세부판정 누적의 위치·배율을 독립적으로 계산합니다. 기존 판정범위의 화면상 위치는 전환 시 보존합니다.
- 10키는 하단에 KPS 3칸 / 정사각 키 2개 / Total 3칸, 12키는 KPS 2칸 / 정사각 키 4개 / Total 2칸으로 사진의 배치를 따릅니다. 하단 키의 레인도 같은 열에 연결합니다.
- 손 20키와 발 6키 배치를 제거합니다. 기존 20키 설정은 첫 16개 키·이름·고스트 등록을 16키로, 기존 발 6키는 첫 4개 키·이름을 발 4키로 전환합니다. 다른 배치의 저장 번호, 발 키 누적 횟수와 사용자 색상·위치는 유지합니다.
- 사망·재시작을 지나서 발키를 계속 누르면 눌림 표시를 유지합니다. 물리적으로 놓을 때 해제하며 상태 복구가 입력 횟수나 KPS를 추가하지 않습니다. 시작 Space 등의 잔류 입력 방지는 유지합니다.
- 일반 키, KPS, Total에 독립적인 색상 설정을 제공합니다. KPS와 Total은 각각 배경·테두리·이름 글자·숫자를 HEX 또는 팔레트로 바꿀 수 있습니다. 기존 색상은 전환 시 각 카운터에 복사해 유지합니다.

0.4.2는 EXE만 제작하며 실제 게임에는 설치하지 않습니다. 검증 범위는 [FEEDBACK_0.4.2_VALIDATION.md](FEEDBACK_0.4.2_VALIDATION.md)에 기록합니다.

## 이전 0.4.1 피드백 반영

- 곡 정보는 위에 작곡가, 아래에 곡명을 표시합니다. 빈 메타데이터를 ScnGame 등 장면 이름으로 대체하지 않으며 곡 정보가 없으면 숨깁니다.
- 플레이 시작 시 이전 눌림 상태·레인·KPS를 비웁니다. 시작할 때 누른 Space 등은 실제로 놓은 뒤 다음 입력부터 정상 처리합니다. 포커스·표시 상태 복구에서도 시작 키가 다시 켜지지 않습니다.
- KeyboardChatterBlocker 같은 SkyHook 입력 필터가 차단한 고스트 키도 레인을 표시합니다. 고스트 입력만 필터 앞에서 관찰하고 일반 입력은 기존 필터를 따르며 키 제한 설정이나 다른 모드 패치를 변경하지 않습니다.
- 고스트 레인은 공유 레인의 모든 일반 레인보다 뒤에서 그립니다. 새 막대 생성·풀 재사용에서도 순서가 유지됩니다.
- Light 대신 원래 Gmarket Sans Medium을 사용합니다. Timing Scale은 1 → 100%, 0.75 → 75%처럼 표시합니다.
- 실제 게임 tracker의 PerfectPlus / XPerfect+Auto / PerfectMinus를 + / X / - 순서로 표시합니다. 게임 통계는 변경하지 않습니다.
- 기본 고스트 레인 색은 #0EB4FCFF입니다. 새 설정과 색상 기본값 복원에 적용하며 저장된 사용자 지정 색은 유지합니다.
- 누적 판정의 과부하 이름을 Overload로 수정하고 게임의 과부하 기본색을 사용합니다. 과부하 수치는 FailOverload만 집계하며 Multipress·OverPress를 더하지 않습니다. 사용자가 지정한 색은 보존합니다.

0.4.1은 EXE만 제작하고 실제 게임에는 설치하지 않았습니다. 검증 범위는 [FEEDBACK_0.4.1_VALIDATION.md](FEEDBACK_0.4.1_VALIDATION.md)에 기록합니다.

## 이전 0.4.0 피드백 반영

- 플레이 중에만 표시: 일반 맵에 진입하면 Space 입력 없이 키뷰어를 표시합니다. 에디터는 재생 여부를 따릅니다. 설정·배치 편집 중에는 미리보기를 표시합니다.
- 설정의 실제 키 배치에서 키를 클릭하면 오른쪽 메뉴로 손·발 입력 키, 표시 이름, 해당 손 키의 고스트 키를 편집합니다. 런타임과 미리보기는 동일한 배치 정보를 사용하며 16키의 50×50 크기와 레인 위치를 보존합니다.
- 고스트 레인은 점선 대신 일반 레인과 같은 채워진 색상으로 표시하며 기본값은 채도 높은 하늘색(#00C8FF)입니다. 기존 기본 흰색만 새 기본색으로 옮기고 사용자 지정 색은 유지합니다.
- 키·레인·오버레이 색은 HEX(#RRGGBB / #RRGGBBAA), HSV 색상·채도·명도, 불투명도 슬라이더 및 색상 팔레트로 지정합니다. 팔레트의 적용/취소를 지원하며 색상 초기화는 배치·입력 횟수·Full 기록을 보존합니다.
- 오버레이 기본 글자, 진행도·정확도·BPM 수치, 콤보, 진행 막대, 세부 +/-와 X, 곡 정보, 타이밍 스케일, 시도 횟수, FPS 및 9개 누적 판정 색을 각각 저장합니다.
- Timing Scale은 다음 판정 타일의 marginScale을 표시하며 세부 판정 누적 위에 배치합니다. 기존 타이밍 섹션 위치만 새 기준으로 옮깁니다.
- 우상단 Pitch 아래 FPS를 표시하고 1초마다 갱신합니다. 표시 여부도 설정할 수 있습니다.
- 진행도 숫자와 막대는 가상 시작 타일을 제외한 타일 진행 비율을 같이 사용합니다. 일시정지·늘어진 타일의 시간 경과만으로 진행도가 오르지 않으며 체크포인트 시작 범위도 같은 타일 기준입니다.
- Attempt / Prg Attempt는 맵을 열어 둔 동안 재시작을 포함해 유지하고 맵을 나가거나 다른 맵을 열면 초기화합니다. Full Attempt / Full Prg Attempt는 계속 저장합니다.
- 설치 창 상단 제목을 내리고 원본 DonQuixote 비활성화 안내 문구를 제거했습니다. 중복 방지 동작은 유지합니다.

0.4.0은 설치 EXE만 제작하고 실행 중인 사용자 게임·설정은 변경하지 않았습니다. 오프라인 DLL·레인·폰트·저장·설치 검사와 실제 인게임 렌더링 검증은 구분합니다. 인게임의 새 편집 메뉴·팔레트·타이밍 위치·시작/재시작/맵 종료 전환은 설치 후 플레이 검증 대상입니다.

- 새 곡 정보와 판정 범위는 설정에서 켜고 끌 수 있으며 레이아웃 편집의 8·9번으로 위치·크기를 조절합니다. 기존 1~7번 배치는 유지합니다.

## 이전 0.3.3 고스트 레인 모양 수정 (0.4.0은 채워진 레인 사용)

고스트 레인의 가로 줄무늬를 지퍼리팩 원본과 같은 속이 빈 점선 테두리로 수정했습니다. 생성 텍스처는 원본 GhostRain.png의 100×100 alpha와 동일하며, 2-pixel sprite border와 uGUI Tiled 표시를 사용합니다. 안쪽은 투명하고 키를 길게 눌러도 가로 띠가 반복되지 않습니다. 고스트 색·키 지정·레인 폭·높이·속도·입력 횟수 설정과 0.3.2의 가림/포화/복구 수정은 유지합니다.

원본 PNG의 alpha 10,000개를 생성 텍스처와 비교하고 점선 테두리·자원 수명·기존 표시 순서/포화/복구를 포함한 레인 검사 28개, Release DLL의 키뷰어 77개 및 로직 80개를 통과했습니다. 이전 가로 줄무늬 자산은 새 모양 검사에서 실패합니다. 이 185개는 오프라인 검사이며 0.3.3의 실제 게임 렌더링 검증과 구분합니다.

## 0.3.2 고스트 레인 표시 수정

0.3.2는 고스트 레인이 간헐적으로 가려지는 문제를 수정합니다. 일반 레인과 고스트 레인의 표시 그룹을 분리해 기존 막대가 새 고스트 막대를 덮지 않도록 했습니다. 창 전환·설정 닫기·플레이 시작 후 이미 누르고 있는 키의 레인도 다시 표시하며, 이 복구는 입력 횟수와 KPS를 올리지 않습니다. 레인이 512개 쌓이면 끝난 오래된 막대를 재사용해 새 고스트 입력을 유지하고, 누르고 있는 키의 막대는 유지합니다. 기존 레인 색·폭·속도·높이 설정은 보존합니다.

실제 Release DLL의 키뷰어 77개·로직 80개·이전 피드백 113개와 레인 production 코드의 API 대체 검사 20개, 관련 총 290개 검사를 통과했습니다. 레인 검사는 공유 레인에서의 가림, 512개 포화 상태와 추가 입력 1,000개, 풀 재사용·파괴 후 복구·클리핑을 포함합니다. 실제 Unity 화면 검증과 구분합니다.

## 게임 판정 설정 연동

판정 텍스트의 크기·숨기기·프리셋·파티클은 게임의 판정 설정에서 조절합니다. Ghostify에는 중복 설정을 두지 않습니다. 파티클 없는 초정확, 부호 판정만 표시하는 경우에도 세부 누적이 표시됩니다. 기본 판정 색 프리셋에서 초정확·부호 판정에 돈키호테 색을 적용하고 게임의 Early/Late 색 또는 ms 부호 색을 선택하면 해당 게임 설정을 따릅니다.

XAccuracy/XScore는 게임의 공식 값입니다. HUD 누적에 Auto를 포함해도 공식 점수 계산을 변경하지 않으며, 미드스핀은 정확 입력 수에 더하지 않습니다. 결과창은 게임이 생성한 ± 셀만 재배치해 원래 숫자·XScore·Auto·다른 행을 보존합니다.

## 이펙트 비활성화

설정창의 **이펙트** 탭에 원본 DonQuixote의 이펙트 설정 영역을 추가했습니다. 원본과 같은 항목 순서·토글 카드 배치·슬라이더와 숫자 입력을 사용하며 현재 흰색·#FFC939 테마와 Gmarket Sans를 적용합니다. 화면 너비 1500 미만에서는 한 열, 그 이상에서는 두 열입니다. 설정창은 이펙트·오버레이·키뷰어 3개 탭으로 구성합니다.

- 전체 **이펙트 비활성화** 스위치와 개별 **VFX 필터 / Bloom / Flash / Hall of Mirrors / 화면 흔들림** 스위치.
- **Move Track 최대 타일 제한**, **Move Track 최대 타일** 슬라이더·직접 입력. 원본 UI 범위 1~101, 기본 30입니다.
- 원본처럼 전체 스위치와 개별 제거 스위치는 기본 꺼짐이며 타일 제한 스위치만 기본 켜짐입니다. 전체 스위치를 켜야 개별 제거와 타일 제한이 작동합니다.
- 원본 필터 예외 목록과 저장 범위 0~9999도 유지합니다. 저장된 0은 제한을 건너뛰며 창을 열기만 해서는 값이 바뀌지 않습니다.

제거·제한 패치와 필터·카메라 상태 복원은 원본 코드를 독립 모드에 연결했습니다. Flash 색상과 Move Track 원본 범위는 이벤트 완료·예외 발생 후 복원합니다. 기능 해제·맵 전환·모드 종료에서도 필터·카메라를 복원하며 실패한 복원은 재시도합니다. 새 효과 연결은 원본처럼 개별 그룹으로 처리하므로 연결 실패는 설정창 상태와 UMM 로그에 표시됩니다. 원본 모드 파일·설정은 변경하거나 자동 이관하지 않습니다.

## 키뷰어

JipperResourcePack의 키뷰어 구조를 이식했습니다. 설정창의 **키뷰어** 탭에서 변경합니다.

- 손 10/12/16키, 발 없음/2/4/8/16키 배치. 기본은 손 16키·발 4키입니다.
- 기본 키는 흰 배경(#FFFFFF)·노란 테두리(#FFC939)·어두운 글자(#292929), 눌린 키는 노란 배경·테두리와 어두운 글자입니다. 레인 1은 #FFC939, 레인 2는 흰색, 고스트 레인은 #0EB4FCFF입니다. 기본값 복원에도 같은 조합을 사용합니다. 이전 기본 팔레트만 새 테마로 옮기며, 다른 사용자 지정 색은 유지합니다.
- 지퍼리팩처럼 손 16키는 **50×50**, 간격 **4**, KPS·Total은 **212×30**으로 고정합니다. 크기는 저장한 키뷰어 배율을 적용하기 전의 기준값입니다. 긴 글자·숫자는 칸 안에 맞춰 글자 크기를 조절합니다. 레인도 원본 폭·위치를 유지합니다.
- 키 직접 등록·해제, 손 키 별칭, 누름/해제 색, 레인·고스트 레인, 레인 속도·높이, 위치·배율, 플레이 중에만 표시.
- 등록 중에는 UI 키보드 이동·확인 동작을 잠시 멈춰 Enter가 등록 버튼을 다시 누르지 않게 합니다. 일반 Enter와 숫자패드 Enter는 별도로 등록·저장합니다. 등록 완료·Esc 취소·탭/씬 전환·창 종료 시 기존 UI 입력 상태를 복원합니다.
- 누적 키 횟수·Total과 최근 1초 실측 KPS. 고스트 키는 집계하지 않습니다. 홀드 반복은 추가 집계하지 않으며 같은 프레임의 여러 down/up을 순서대로 처리합니다.
- 원본처럼 **표시 칸마다** 집계합니다. 같은 물리 키를 두 칸에 등록하면 Total/KPS에도 두 칸 분량을 더합니다. KPS는 기존 BPM 기반 이론 KPS와 별개입니다.
- 설정창과 레이아웃 편집 중에는 등록·미리보기 입력을 집계하지 않습니다. 포커스·씬 전환 시 일시 상태와 레인을 정리합니다.
- **게임 입력 키 자동 연동**(기본 켜짐): 현재 손·발 배치의 키를 게임의 ‘특정 키만 입력으로 간주’ 목록에 자동 반영합니다. 고스트·미등록 키는 제외하고 중복을 제거합니다. 일반 입력·비동기 입력 목록을 모두 갱신합니다. 연동을 끄면 게임 목록을 직접 편집할 수 있으며 최초 연동 전 목록은 UserData/native-input-before-sync.json에 보관합니다. 게임의 Windows 비동기 허용 목록은 두 Enter가 같은 VK_RETURN이므로 둘 중 하나를 등록하면 양쪽 Enter를 허용합니다. 키뷰어 슬롯과 일반 입력 목록은 계속 두 키를 구분합니다.
- 기본 레인은 켜짐, 고스트 레인은 꺼짐입니다. 누적 횟수 초기화는 확인 버튼을 두 번 눌러 실행합니다.

SkyHook 이벤트를 별도 큐로 관찰하고 Unity 객체는 메인 스레드에서 갱신합니다. 이벤트 입력을 사용할 수 없으면 Unity 프레임 입력으로 전환하며 설정창 상태에 정확도 제한을 표시합니다. 프레임 입력에서는 프레임 사이에 끝난 짧은 연타를 놓칠 수 있습니다.

## 레이아웃 편집과 저장

오버레이 탭의 **섹션 위치·크기 편집**에서 기존 여섯 통계 섹션과 키뷰어, 곡 정보, 판정 범위를 편집합니다. 1~9 또는 Tab으로 선택, 방향키로 이동, Shift로 이동 간격 확대, Ctrl+↑↓로 크기 조절, Enter로 저장, Esc로 취소합니다. 씬 전환·설정창 열기·모드 해제에서도 편집을 취소합니다. 통계 판정 숫자는 글자 크기를 유지한 채 공간을 늘리고 키뷰어 글자는 고정된 칸 안에 맞춥니다. 저장한 섹션 위치·크기와 키뷰어 배율을 유지합니다.

새 모드 경로의 UserData/settings.json, layout.json, keyviewer.json, keyviewer-counts.json만 사용합니다. 카운트는 변경 시 최대 5초 간격과 종료·설정 저장 때 저장하며 JSON 손상 시 파일을 보존하고 이전 백업으로 복구합니다. 원본 DonQuixote 설정을 자동으로 읽거나 이관하지 않습니다.
