# Ghostify Overlay 0.2.9

## 설치

[비공개 GitHub 릴리스](https://github.com/vista102/GhostifyOverlay/releases/latest)에서 **GhostifyOverlay-Setup-0.2.9.exe**를 받습니다. Windows 10/11, .NET Framework 4.8, Unity Mod Manager 0.33.0 이상이 설치된 얼불춤을 사용합니다.

게임을 완전히 종료하고 EXE를 실행한 뒤 자동으로 찾은 게임 폴더를 확인하고 **설치하기 / 업데이트**를 누릅니다. 직접 폴더를 선택할 수도 있습니다. 기존 키 색상·배치·설정·누적 기록은 유지하고 이전 모드·UMM 설정을 자동으로 백업합니다. 설치 실패 시 변경한 파일을 복원합니다. 첨부 캐릭터를 설치 화면과 EXE 아이콘에 사용했습니다. 자세한 제작·복원 안내는 [설치 프로그램 문서](Installer/README.md)에 있습니다.

## 모드 사용

독립 UMM 모드입니다. **Alt+D**로 설정창을 열고 **Esc**로 닫습니다. 전체 설정창·통계 오버레이·키뷰어·레이아웃 안내를 흰색·노란색(#FFCA3A) uGUI/TMP로 구성했습니다. 노란 버튼·흰 표면에는 읽기 쉬운 어두운 글자를 사용합니다.

모든 설정 토글은 캡슐형 트랙과 흰색 원형 손잡이를 사용합니다. 켜짐은 노란색(#FFCA3A), 꺼짐은 회색이며 손잡이에 작은 그림자를 넣었습니다. 트랙과 손잡이는 늘어나지 않는 고정 비율로 표시하고 글자와의 간격을 확보합니다.

설정창 테두리는 카드 안쪽에 한 겹으로 그려 모서리와 직선의 두께를 맞췄습니다. 픽셀 정렬을 적용하고 이펙트 카드·슬라이더의 바깥쪽 좌우 경계를 통일했습니다. 우측 상단은 테두리·바탕 없는 X 닫기 버튼이며 아이콘 주변까지 클릭할 수 있습니다.

영어 UI는 Google Sans를 사용하며 한글은 Noto Sans KR Regular로 표시합니다. 설정창·통계 오버레이·키뷰어·레이아웃 안내에서 같은 한글 폰트를 사용합니다. 통계 오버레이 글자에는 검은 그림자를 적용했습니다. 게임에 뜨는 XPerfect 및 +/-Perfect를 포함한 판정 텍스트는 게임의 원래 폰트·머티리얼을 유지합니다. 누적 판정은 원본 DonQuixote의 판정별 색, 세부 판정은 +/- 녹색(#60FF4E)과 X 하늘색(#4DCCFF)을 사용합니다. 세부 누적·결과창은 왼쪽부터 **+ / X / -** 순서입니다. 자동플레이 타일은 일반 누적의 Perfect와 세부 누적의 XPerfect에 포함합니다. 첫 판정 전 유효하지 않은 Accuracy/XAccuracy는 100.00%로 표시하고 실제 Perfect 보너스가 포함된 100% 초과 정확도는 유지합니다.

## 판정 텍스트 크기

**Alt+D → 판정 → 판정 텍스트 크기**에서 원본과 같은 슬라이더와 숫자 입력으로 조절합니다. 범위는 **0.4~1.2**이며 소수 단위로 연속 조절됩니다. 기존 저장 크기는 그대로 유지합니다.

## 이펙트 비활성화

설정창의 **이펙트** 탭에 원본 DonQuixote의 이펙트 설정 영역을 추가했습니다. 원본과 같은 항목 순서·토글 카드 배치·슬라이더와 숫자 입력을 사용하며 현재 흰색·#FFCA3A 테마와 Google Sans를 적용합니다. 화면 너비 1500 미만에서는 한 열, 그 이상에서는 두 열입니다. 기존 입력·판정·오버레이·키뷰어 탭은 유지합니다.

- 전체 **이펙트 비활성화** 스위치와 개별 **VFX 필터 / Bloom / Flash / Hall of Mirrors / 화면 흔들림** 스위치.
- **Move Track 최대 타일 제한**, **Move Track 최대 타일** 슬라이더·직접 입력. 원본 UI 범위 1~101, 기본 30입니다.
- 원본처럼 전체 스위치와 개별 제거 스위치는 기본 꺼짐이며 타일 제한 스위치만 기본 켜짐입니다. 전체 스위치를 켜야 개별 제거와 타일 제한이 작동합니다.
- 원본 필터 예외 목록과 저장 범위 0~9999도 유지합니다. 저장된 0은 제한을 건너뛰며 창을 열기만 해서는 값이 바뀌지 않습니다.

제거·제한 패치와 필터·카메라 상태 복원은 원본 코드를 독립 모드에 연결했습니다. Flash 색상과 Move Track 원본 범위는 이벤트 완료·예외 발생 후 복원합니다. 기능 해제·맵 전환·모드 종료에서도 필터·카메라를 복원하며 실패한 복원은 재시도합니다. 새 효과 연결은 원본처럼 개별 그룹으로 처리하므로 연결 실패는 설정창 상태와 UMM 로그에 표시됩니다. 원본 모드 파일·설정은 변경하거나 자동 이관하지 않습니다.

## 키뷰어

JipperResourcePack의 키뷰어 구조를 이식했습니다. 설정창의 **키뷰어** 탭에서 변경합니다.

- 손 10/12/16/20키, 발 없음/2/4/6/8/16키 배치. 기본은 손 16키·발 4키입니다.
- 2026-10-03 인게임에서 저장한 키 색상 9개를 기본값으로 사용합니다. 기본 키는 검은 배경(#000000)·노란 테두리(#FFCA3A)·흰 글자, 눌린 키는 노란 배경·테두리와 어두운 글자(#292929)입니다. 레인 1/3은 #FFCA3A, 레인 2는 흰색입니다. **키 색상 기본값으로 복원**도 이 조합을 사용합니다. 기존에 저장한 색상은 덮어쓰지 않습니다.
- 지퍼리팩처럼 손 16키는 **50×50**, 간격 **4**, KPS·Total은 **212×30**으로 고정합니다. 크기는 저장한 키뷰어 배율을 적용하기 전의 기준값입니다. 긴 글자·숫자는 칸 안에 맞춰 글자 크기를 조절합니다. 레인도 원본 폭·위치를 유지합니다.
- 키 직접 등록·해제, 손 키 별칭, 누름/해제 색, 레인·고스트 레인, 레인 속도·높이, 위치·배율, 플레이 중에만 표시.
- 등록 중에는 UI 키보드 이동·확인 동작을 잠시 멈춰 Enter가 등록 버튼을 다시 누르지 않게 합니다. 일반 Enter와 숫자패드 Enter는 별도로 등록·저장합니다. 등록 완료·Esc 취소·탭/씬 전환·창 종료 시 기존 UI 입력 상태를 복원합니다.
- 누적 키 횟수·Total과 최근 1초 실측 KPS. 고스트 키는 집계하지 않습니다. 홀드 반복은 추가 집계하지 않으며 같은 프레임의 여러 down/up을 순서대로 처리합니다.
- 원본처럼 **표시 칸마다** 집계합니다. 같은 물리 키를 두 칸에 등록하면 Total/KPS에도 두 칸 분량을 더합니다. KPS는 기존 BPM 기반 이론 KPS와 별개입니다.
- 설정창과 레이아웃 편집 중에는 등록·미리보기 입력을 집계하지 않습니다. 포커스·씬 전환 시 일시 상태와 레인을 정리합니다.
- 손·발 키를 허용 키 목록에 복사하는 버튼은 기존 목록을 교체합니다. 키 제한을 자동으로 켜지 않습니다. 빈 허용 목록에서는 키 제한을 사용할 수 없습니다.
- 기본 레인은 켜짐, 고스트 레인은 꺼짐입니다. 누적 횟수 초기화는 확인 버튼을 두 번 눌러 실행합니다.

SkyHook 이벤트를 별도 큐로 관찰하고 Unity 객체는 메인 스레드에서 갱신합니다. 이벤트 입력을 사용할 수 없으면 Unity 프레임 입력으로 전환하며 설정창 상태에 정확도 제한을 표시합니다. 프레임 입력에서는 프레임 사이에 끝난 짧은 연타를 놓칠 수 있습니다.

## 레이아웃 편집과 저장

오버레이 탭의 **섹션 위치·크기 편집**에서 기존 여섯 통계 섹션과 키뷰어를 편집합니다. 1~7 또는 Tab으로 선택, 방향키로 이동, Shift로 이동 간격 확대, Ctrl+↑↓로 크기 조절, Enter로 저장, Esc로 취소합니다. 씬 전환·설정창 열기·모드 해제에서도 편집을 취소합니다. 통계 판정 숫자는 글자 크기를 유지한 채 공간을 늘리고 키뷰어 글자는 고정된 칸 안에 맞춥니다. 저장한 섹션 위치·크기와 키뷰어 배율을 유지합니다.

새 모드 경로의 UserData/settings.json, layout.json, keyviewer.json, keyviewer-counts.json만 사용합니다. 카운트는 변경 시 최대 5초 간격과 종료·설정 저장 때 저장하며 JSON 손상 시 파일을 보존하고 이전 백업으로 복구합니다. 원본 DonQuixote 설정을 자동으로 읽거나 이관하지 않습니다.

## 출처와 검증

키뷰어 기준 커밋은 JipperResourcePack ac6d6410571ee7d585aedce7f5085de34f615af2입니다. 클래스 관계·기본 크기와 배치·슬롯 집계·레인 계산을 유지하고 독립 모드 연결, uGUI 설정, 안전한 저장과 자원 정리를 조정했습니다. JALib·IMGUI·DOTween 추가 의존성은 없습니다. BSD 고지와 Google Sans OFL은 배포물에 포함합니다. 자세한 출처는 THIRD-PARTY-NOTICES.md를 참고하세요.

0.2.1의 폰트 초기화 오류 수정을 유지합니다. 0.2.9 Release 빌드 오류·경고 0, 이번 테두리·정렬·닫기 버튼 수정과 관련된 로직 139·이펙트/UI 69로 208개 검사를 통과했습니다. 실제 바탕·테두리·X·토글 픽셀 생성 코드로 만든 미리보기에서 같은 모서리 곡선과 테두리 없는 X 아이콘을 확인했습니다. 변경되지 않은 기능은 0.2.7의 전체 379개 검사 결과를 유지합니다. Noto Sans KR의 family·Regular face·원본/변환 해시·OFL 배포와 한글 음절 11,172개 포함을 확인했습니다. API 대체 검사와 미리보기는 게임 화면을 실행하는 검사가 아닙니다. 인게임 화면·입력·판정 미터·이펙트, 해상도별 표시, 성능과 타 모드 호환성은 사용자 실행 검증 대기입니다.

프로젝트 폴더·프로젝트 파일·빌드 이름은 GhostifyOverlay, 모드 매니저와 설정창 표시명은 Ghostify Overlay입니다. 기존 설치의 설정·배치·기록이 그대로 이어지도록 내부 UMM ID와 저장 경로는 호환을 유지합니다.

## 소스에서 빌드

Visual Studio 2022 Build Tools와 .NET Framework 4.8을 사용합니다. 게임/Unity/UMM 제공 DLL은 저장소에 포함하지 않으며 설치된 게임 폴더를 참조합니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File Build.ps1 -GameDir '게임 폴더'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File Installer\Build-Setup.ps1 -GameDir '게임 폴더'
```

인게임 UI는 uGUI/TMP이고 설치 프로그램은 Windows Forms입니다. 사용자 설정, 복구 백업, 생성된 게임 API 비교 파일과 로컬 검증 기록은 저장소에서 제외합니다. 영문·한글 폰트와 지퍼리팩 라이선스 고지는 함께 제공합니다.
