# Ghostify Overlay

얼불춤의 플레이 정보와 키 입력을 보여주는 오버레이 모드입니다.

- **오버레이** — 판정, 콤보, 진행도, 정확도, 시도 횟수, 곡 정보, Timing Scale, FPS
- **키뷰어** — 손·발 입력, 고스트 레인, KPS, 누적 입력 횟수
- **커스터마이징** — 표시 항목, 위치·크기, 색상·행간, 이름을 붙여 저장하는 키 배치 프리셋

## 다운로드

**[Windows 설치 파일 받기 · v0.5.6 EXE](https://github.com/vista102/GhostifyOverlay/releases/download/v0.5.6/GhostifyOverlay-Setup-0.5.6.exe)**

[모드 ZIP](https://github.com/vista102/GhostifyOverlay/releases/download/v0.5.6/GhostifyOverlay-0.5.6.zip) · [파일 검증용 SHA256](https://github.com/vista102/GhostifyOverlay/releases/download/v0.5.6/SHA256SUMS.txt) · [전체 릴리스](https://github.com/vista102/GhostifyOverlay/releases)

처음 설치하거나 업데이트할 때는 **EXE**를 사용하면 됩니다.

## 설치

| 항목 | 지원 환경 |
|---|---|
| 운영체제 | Windows 10 / 11 |
| 게임 | 얼불춤 3.4.0 alpha · build 26311090 |
| 모드 매니저 | Unity Mod Manager 0.32.5 이상 |
| 실행 환경 | .NET Framework 4.8 |

1. 위 **Windows 설치 파일 받기**에서 `GhostifyOverlay-Setup-0.5.6.exe`를 다운로드합니다.
2. **게임을 종료한 뒤** EXE를 실행합니다.
3. 게임 폴더를 확인하고 **설치하기 / 업데이트**를 누릅니다.
4. 게임을 실행하고 Unity Mod Manager에서 **Ghostify Overlay**를 활성화합니다.

업데이트해도 기존 설정·키 배치·누적 기록은 유지됩니다. 설치 위치는 `Mods/Ghostify Overlay`이며, 이전 `DonQuixoteOverlay` 폴더는 EXE 업데이트 시 자동 이전합니다.

처음 설치하면 **손 16키·발 16키 · 검정 배경 · 흰 글자 · 노란 테두리 · 하늘색 고스트 레인**이 적용됩니다.

## 기본 조작

| 동작 | 조작 |
|---|---|
| 설정창 열기 | **Alt+D** |
| 설정창 닫기 | **Esc** 또는 우측 상단 **X** |
| 설정 선택 | 왼쪽 분류를 선택하고 오른쪽에서 조절 |
| 상세 영역 이동 | 마우스 휠 · 분류별 스크롤 위치 유지 |
| 색상 선택 | HEX 입력 또는 입력칸 옆 색상 네모 클릭 |

팔레트·프리셋 창·키 등록 중 **Esc**를 누르면 해당 작업만 취소합니다.

## 오버레이 설정

- **표시 항목:** 6개 그룹에서 그룹 전체와 개별 항목을 각각 켜고 끕니다.
- **행간·색상:** **오버레이 → 공통 스타일**에서 조절합니다. 행간 `0`은 기존 간격입니다.
- **색상 범위:** 수치·시도 횟수·진행 막대 색상을 변경할 수 있습니다. 글자·곡 정보·타이밍은 흰색으로 고정됩니다.
- **곡명 / 작곡가:** Ghostify 곡 정보가 표시되면 게임 기본 곡 정보는 숨겨지고, 끄면 원래 상태로 돌아옵니다. ADOFAI Tweaks의 숨김 설정은 유지합니다.

Pitch는 백분율로 표시하며, FPS는 초당 10회 갱신합니다. 판정 텍스트의 크기·숨기기는 게임 설정에서 변경합니다. 게임에서 세부 판정을 끄면 Ghostify의 세부 누적 판정도 함께 숨겨집니다.

### 위치·크기 편집

설정창 상단의 **위치·크기 편집** 버튼을 누르면 화면에서 직접 조절할 수 있습니다.

| 동작 | 조작 |
|---|---|
| 편집할 항목 선택 | 숫자 **1~9·0** 또는 **Tab** |
| 위치 이동 | **방향키** · 길게 누르면 연속 이동 |
| 빠르게 이동 | **Shift + 방향키** |
| 크기 변경 | **Ctrl + ↑ / ↓** |
| 저장 후 설정창으로 복귀 | **Enter** |
| 취소 후 설정창으로 복귀 | **Esc** |

## 키뷰어 설정

**키뷰어 → 키 배치·프리셋**에서 손 **4·8·10·12·16키**와 발 배치를 선택합니다. 미리보기의 키를 클릭하면 오른쪽에서 **입력 키·표시 이름·고스트 키**를 변경할 수 있습니다.

| 설정 | 위치·동작 |
|---|---|
| 키 간격 | **표시·간격** · `0~30`, 기본 `3` · 키와 레인의 크기 유지 |
| 키·KPS·Total 색상 | **색상**에서 대상 선택 |
| 레인 색상 | **레인**에서 상단·하단·고스트 레인 설정 |
| 게임 입력 키 자동 연동 | **입력** · 등록한 손·발 키를 게임의 **특정 키만 입력으로 간주**에 반영 · 고스트 키 제외 |
| 채터링 차단 | **입력** · `0~500ms`, 기본 **ON / 70ms** · 플레이 중에만 적용 |

16키의 **KPS / Total**은 항상 표시됩니다. 기존 KeyboardChatterBlocker가 활성화되어 있으면 내장 채터링 차단은 대기합니다.

### 프리셋 저장·공유

| 작업 | 방법 |
|---|---|
| 새 프리셋 저장 | **새로 저장**을 누르고 이름 지정 |
| 불러오기 | 목록에서 미리 확인한 뒤 **불러오기** |
| 직전 구성 복원 | **이전 구성으로** |
| 저장된 프리셋 갱신 | **⋯ → 현재 구성으로 덮어쓰기** |
| 이름 변경·복제·삭제 | **⋯** 메뉴 |
| JSON 가져오기·내보내기 | **⋯** 메뉴 · 가져올 파일은 전체 경로 입력 |
| 내보낸 파일 확인 | **프리셋 폴더 열기** |

현재 구성의 변경은 자동 저장됩니다. 저장된 프리셋을 갱신하려면 **덮어쓰기**를 사용합니다. 첫 실행 시 현재 구성은 **기존 설정**으로 보관합니다.

**프리셋에 저장:** 손·발 배치, 입력 키, 키 표시 이름, 고스트 키

**공통 설정으로 유지:** 색상, 레인, 위치, 입력 옵션

## 커스텀 텍스트

**오버레이 → 6 · 커스텀 텍스트**에서 최대 50개의 텍스트를 추가·삭제할 수 있습니다.

- **+**로 새 항목을 추가하고, 카드의 입력칸에서 내용을 바로 수정합니다. 줄바꿈도 지원합니다.
- 왼쪽 토글로 항목을 켜고 끄며, 오른쪽 색상 네모로 팔레트·HEX 색상을 선택합니다.
- **위치·크기 조절**을 누르면 설정창이 닫히고 실제 화면에 해당 텍스트의 예시가 표시됩니다. 게임 플레이 중이 아니거나 항목 표시가 꺼져 있어도 편집 예시를 볼 수 있습니다.
- **방향키**로 이동하고 길게 누르면 연속 이동합니다. **Shift**로 빠르게 이동하고 **Ctrl+↑/↓**로 글자 크기를 바꿉니다.
- **Enter**로 저장하거나 **Esc**로 취소하면 설정창으로 돌아옵니다. 저장 전 편집값은 임시값으로 유지합니다.
- **×**로 해당 항목을 삭제합니다.

각 항목은 독립적으로 저장되며 텍스트의 HTML/TMP 태그는 그대로 표시합니다.

## TUFReplay 호환

게임 안에서 리플레이 오버레이를 보려면 **ReplayApi 2를 지원하는 TUFReplay**를 활성화한 뒤 저장된 리플레이를 재생합니다. ReplayApi 1만 지원하는 이전 TUFReplay에는 연결하지 않습니다. 영상에 오버레이를 넣으려면 **OrbitRender 2.8.0 이상**도 활성화하고 TUFReplay에서 영상 만들기를 실행합니다. [TUFReplay 다운로드](https://github.com/KGH1113/TUFReplay/releases) · [OrbitRender 다운로드](https://github.com/imnyang/OrbitRender/releases)

녹화 당시의 시도 횟수, 시작 지점, 최고 진행도, 키별 누적 횟수를 리플레이와 함께 저장합니다. 재생하면 기록된 키 입력과 레인·KPS가 리플레이 시간에 맞춰 표시됩니다. 오버레이 상태가 저장되기 전에 녹화한 리플레이는 현재 카운터를 기준으로 표시합니다.

리플레이 중 표시되는 키 카운터와 시도 횟수는 실제 플레이 기록과 별도로 관리됩니다. Windows 전용 키 바인딩을 재현하려면 게임 내 리플레이가 해당 키 코드를 제공해야 합니다. 일반 플레이의 오버레이와 키뷰어는 TUFReplay나 OrbitRender 없이도 사용할 수 있습니다.

## 시도 횟수와 기록

**최고 진행도(Best)**는 **오버레이 → 5 · 시도 횟수**에서 표시를 켜고 끕니다. 시도 횟수 블록 아래에 반 줄 간격으로 표시되며, 블록과 함께 이동·확대됩니다.

첫 타일부터 시작한 일반 플레이만 집계합니다. 자동플레이·맵 전체 무적·무한 판정 범위를 사용한 플레이와 체크포인트·중간 시작은 제외합니다. 플레이 도중 해당 모드를 켠 경우도 그 시도의 기록을 저장하지 않습니다. 최고 기록은 타일 진행도와 레벨 해시를 기준으로 맵별 저장하며, 맵을 나가거나 외형을 초기화해도 유지됩니다. 이전 기록보다 짧은 시도는 최고 기록을 낮추지 않습니다.

### 현재 맵 기록 초기화

**오버레이 → 5 · 시도 횟수**에서 각각 따로 초기화할 수 있습니다.

- **현재 맵 시도 횟수 초기화:** 이 맵의 Attempt·Prac Attempt·Full Attempt·Full Prac Attempt를 0으로 초기화합니다. 최고 진행도는 유지합니다.
- **현재 맵 최고 진행도 초기화:** 이 맵의 Best를 0%로 초기화합니다. 시도 횟수는 유지하며, 현재 진행 중인 시도는 제외하고 다음 시도부터 새로 기록합니다.

두 기능 모두 다른 맵의 기록은 유지합니다. 맵을 불러온 상태에서만 사용할 수 있고, 확인창을 연 뒤 맵이 바뀌면 초기화하지 않습니다.

| 표시 | 집계 기준 | 초기화 시점 |
|---|---|---|
| **Attempt** | 맵 처음부터 시작한 시도 횟수 | 맵을 나갈 때 |
| **Prac Attempt** | 체크포인트 또는 맵 중간부터 시작한 연습 시도 횟수 | 맵을 나갈 때 |
| **Full Attempt** | 처음부터 시작한 시도의 전체 누적 | 맵을 나가도 유지 |
| **Full Prac Attempt** | 중간부터 시작한 연습 시도의 전체 누적 | 맵을 나가도 유지 |

`Prac`은 **Practice(연습)**의 줄임말입니다. 예를 들어 처음부터 재시작하면 **Attempt**, 체크포인트에서 재시작하면 **Prac Attempt**만 올라갑니다. 두 횟수는 따로 집계합니다.

판 시작 시 자동플레이·맵 전체 무적 여부로 집계합니다. 시작 후 모드를 바꿔도 이미 집계한 횟수는 유지하며, 자유 이동 구간 무적 옵션은 일반 시도 집계를 막지 않습니다.
